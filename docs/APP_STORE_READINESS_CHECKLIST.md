# App Store Readiness Checklist

This is not a store submission phase. This checklist is here so future phases stay organized.

## Game readiness

- [ ] All 18 campaign levels are playable.
- [ ] Daily Job saves correctly.
- [ ] Quick Play saves correctly.
- [ ] Achievements unlock once and persist.
- [ ] Stats match saved progress.
- [ ] Reset progress clears the right data.
- [ ] No horizontal overflow on phone.
- [ ] PWA/offline behavior works in local preview.

## Android wrapper readiness

- [ ] `npm.cmd run build` works locally.
- [ ] `npm.cmd run preview:host` works on phone over Wi-Fi.
- [ ] Android Studio installed.
- [ ] JDK/Android SDK installed.
- [ ] `npx cap add android` runs successfully.
- [ ] Installed debug APK runs on a real Android phone.

## Store listing readiness later

- [ ] Final app icon.
- [ ] Google Play feature graphic.
- [ ] Phone screenshots.
- [ ] Short description.
- [ ] Full description.
- [ ] Privacy policy page.
- [ ] Support email/page.
- [ ] Content rating questionnaire.
- [ ] Closed testing plan if Google Play requires it.
